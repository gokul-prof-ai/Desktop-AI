# Contributing to Desktop-AI

We welcome contributions! Here's how to help.

## Code of Conduct

- Be respectful
- Focus on code, not person
- Help others learn

## Getting Started

1. Fork repository
2. Create feature branch
3. Make changes
4. Test thoroughly
5. Submit pull request

## Contribution Types

### 🐛 Bug Reports

- Use issue template
- Include steps to reproduce
- Add system info (Python version, OS)

### ✨ New Features

- Discuss in issues first
- Follow architecture guidelines
- Add tests (80%+ coverage)
- Update documentation

### 📖 Documentation

- Grammar/clarity fixes welcome
- Add examples
- Update outdated sections

### ⚡ Performance

- Benchmark before/after
- Profile with cProfile
- Document optimization technique

## Pull Request Process

1. Update CHANGELOG.md
2. Pass all tests
3. Update docs if needed
4. Wait for review
5. Address feedback

## Code Standards

- Black formatting
- Type hints for public APIs
- Google-style docstrings
- 80%+ test coverage
