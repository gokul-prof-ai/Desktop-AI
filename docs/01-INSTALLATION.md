# Installation Guide

## System Requirements

- Windows 10/11 (or WSL2 on Linux)
- Python 3.13
- 2GB RAM minimum, 4GB recommended
- 500MB disk space

## Dependencies

### Core

- SQLite (built-in)
- NumPy, FAISS (semantic search)
- Ollama (local LLM)

### Optional

- Tesseract (OCR for images)
- GraphViz (architecture diagrams)
